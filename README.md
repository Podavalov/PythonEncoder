🕵️‍♂️ Python Obfuscator (Обфускатор Python-кода)

Скрой логику вашего Python-проекта от посторонних глаз!

Этот инструмент автоматически обрабатывает весь ваш Python-проект, усложняя его понимание для человека. Он создает полную копию директории, оставляя оригинальные файлы нетронутыми.

Обфускация (запутывание кода) — это отличный способ защитить интеллектуальную собственность, когда вы не можете использовать компиляцию, но хотите затруднить обратную разработку (reverse engineering).
✨ Что умеет программа?

Программа комплексно подходит к задаче и выполняет три основных типа преобразований:

    🔀 Замена идентификаторов:

        Все значимые имена в вашем коде (переменные, функции, классы, аргументы, импорты) переименовываются в случайные короткие буквенно-цифровые комбинации.

        Например, user_data превратится в jK7sA2L.

        Имена из списка modulesFilter.txt (встроенные функции, стандартные библиотеки, популярные библиотеки вроде pandas или django) заменяться не будут, чтобы код оставался рабочим.

    🔢 Обфускация чисел:

        Все числа в коде заменяются на их "запутанное" представление.

        Целые числа (42) превращаются в int('0b101010', 0).

        Числа с плавающей точкой (3.14) превращаются в вызовы struct.unpack, что выглядит как struct.unpack('>d', bytes.fromhex('40091eb851eb851f'))[0].

        Это отлично маскирует математическую логику и настройки.

    📁 Работа с копией проекта:

        Инструмент никогда не изменяет вашу исходную директорию.

        Он создает её точную копию с суффиксом _obfuscated.

        Если такая папка уже существует, программа автоматически добавит номер (например, _obfuscated_1), чтобы не перезаписывать данные.

🚀 Как использовать
Требования

    Python 3.9 или выше (используется ast.unparse).

Установка

    Скачайте все файлы проекта в одну папку.

    Убедитесь, что у вас есть файлы:

        main.py — точка входа.

        fileCollector.py, variableReceiver.py, randomNameGenerator.py, renameEngine.py, numberObfuscator.py — ядро программы.

        modulesFilter.txt — база "защищенных" имен.

Запуск

    Откройте терминал или командную строку.

    Перейдите в папку с программой.

    Выполните команду:
    bash

    python main.py

    Введите путь к папке с вашим проектом, которую вы хотите обфусцировать.
    text

    Введите путь к директории: C:/Users/Me/MyProject

Результат

    Через некоторое время в папке, содержащей ваш проект, появится новая папка с именем MyProject_obfuscated.

    Внутри неё будет весь ваш код, но теперь он выглядит как "кириллица" для программиста. 😉

Пример "до" и "после":

До:
python

def calculate_total(price, tax):
    result = price * (1 + tax)
    return result

После:
python

def dJk2L(sD3f, hG7s):
    aB9q = sD3f * (float(int('0b1', 0)) + hG7s)
    return aB9q

⚙️ Как это работает (для разработчиков)

Инструмент использует продвинутые методы работы с Python AST.

    Сбор имен: Модуль variableReceiver анализирует каждый файл в копии и собирает все имена, которые можно заменить (функции, переменные, аргументы и т.д.).

    Фильтрация: Все собранные имена сравниваются со списком из modulesFilter.txt. Этот список включает в себя:

        Встроенные слова языка (print, len, True).

        Имена стандартных библиотек (sys, os).

        Названия популярных сторонних библиотек (pandas, matplotlib).

        "Магические" методы классов (__init__, __str__).

        Служебные имена (часто используемые аргументы вроде self, cls).

    Генерация пар: Оставшиеся имена случайным образом сопоставляются с новыми короткими идентификаторами.

    Замена: renameEngine проходит по AST (дереву разбора) всех файлов и меняет все старые имена на новые.

    Числа: numberObfuscator аналогичным образом обрабатывает AST, находя числовые литералы и заменяя их на сгенерированные выражения.

📄 Список исключений (modulesFilter.txt)

Этот файл содержит огромный список зарезервированных имен, которые программа игнорирует. Вы можете редактировать этот файл.

    Добавьте свои собственные имена, которые не должны меняться (например, названия API ключей в коде).

    Удалите имена из списка, если хотите, чтобы они тоже были заменены (делайте это с осторожностью, это может сломать код).

🛠️ Устранение неполадок

    Ошибка SyntaxError при обработке файла:

        Это значит, что в вашем файле есть синтаксическая ошибка, которую AST не может разобрать.

        Программа пропустит этот файл (изменен он не будет), но продолжит работу. Проверьте такие файлы вручную.

    Ошибка ast.unparse недоступен:

        Обновите вашу версию Python до 3.9 или выше.

    Программа зависла или работает слишком долго:

        Код генерирует уникальные случайные имена для каждого старого имени. Сложность алгоритма высокая, но для проектов среднего размера (до 1000 файлов) это занимает пару секунд.
