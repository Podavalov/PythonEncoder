
# PythonEncoder

**PythonEncoder** — программа для защиты Python‑скриптов.  
Она позволяет:

- защищать отдельные `.py`‑файлы (с помощью `encoder.py`);
- пакетно обрабатывать целые директории (с помощью `main.py`);
- запускать защищённые файлы;
- привязывать скрипты к конкретной машине;
- ограничивать срок действия скриптов.

## Команды `encoder.py`

### 1. Показать код машины

```bash
python encoder.py machine
```
Выводит идентификатор текущей машины (16 символов).
2. Защитить один файл
```bash

python encoder.py protect app.py -o app.guarded.py
```
Параметры:
Параметр	Описание
input	Исходный .py‑файл
-o, --output	Выходной файл (по умолчанию input.guarded.py)
--key	Ключ шифрования (если не указан – генерируется случайный)
--machine	Привязка: any, auto или код машины
--no-machine	Отключить привязку (эквивалент --machine any)
--expire-days	Срок действия в днях (0 – бессрочно)

Пример:
```bash

python encoder.py protect app.py --key secret --machine auto --expire-days 30
```
3. Запустить защищённый файл
```bash

python encoder.py run app.guarded.py
```
Пакетная защита (main.py)

Скрипт main.py автоматически:

    Создаёт копию указанной директории с суффиксом _encrypted (если такая уже существует, добавляет номер).

    Находит все .py‑файлы (кроме скрытых папок).

    Применяет к каждому из них защиту с одинаковыми параметрами (ключ, привязка, срок).

    Перезаписывает файлы в копии (оригиналы остаются нетронутыми).

Использование
```bash

python main.py [путь_к_директории] [--key КЛЮЧ] [--machine any|auto|код] [--expire-days ДНИ] [--no-machine] [--interactive]
````
Аргументы командной строки
Аргумент	Описание
directory	Путь к директории с исходными .py‑файлами (обязательный, если не включён интерактивный режим).
--key	Общий ключ для всех файлов. Если не указан, генерируется случайный.
--machine	Привязка: any (по умолчанию), auto (текущая машина) или конкретный код.
--no-machine	Отключает привязку (эквивалент --machine any).
--expire-days	Срок действия в днях (по умолчанию 0 – бессрочно).
--interactive	Запрашивать параметры интерактивно, даже если заданы аргументы.

Если аргументы не переданы, main.py запустится в интерактивном режиме и запросит все параметры.
Примеры пакетной защиты

1. Защитить всю папку с ключом и без привязки
```bash

python main.py /home/user/my_project --key my-common-key --no-machine
````
2. Защитить с автоматической привязкой к текущей машине и сроком 7 дней
```bash

python main.py ./project --machine auto --expire-days 7
```
3. Интерактивный режим (запросит путь и параметры)

```bash
python main.py
```

Как это работает (внутреннее устройство)

    При защите файла его код шифруется с помощью XOR и ключа, выведенного из MAGIC + ключ + "|payload" через SHA‑256.

    Метаданные (срок и привязка) также шифруются и встраиваются в файл.

    Защищённый файл представляет собой Python‑скрипт, который при запуске или импорте:

        расшифровывает метаданные;

        проверяет машину и срок;

        расшифровывает и выполняет исходный код в изолированном пространстве имён;

        экспортирует все определённые в исходном коде глобальные имена в текущий модуль.

Благодаря этому защищённый файл можно использовать как обычный модуль — все функции, классы и переменные будут доступны после импорта.
Частые ошибки и их решение
Ошибка	Причина	Решение
«Срок действия истёк»	Файл создан с --expire-days, и срок прошёл.	Создать новый защищённый файл с бóльшим сроком.
«Скрипт защищён для другой машины»	Файл привязан к другой машине.	Использовать --machine any при создании или запускать на той машине, для которой он был создан.
Файл не запускается	Некорректный Python, отсутствие файла или неправильный путь.	Проверить установку Python, существование файла и правильность пути.
Краткая памятка
Что сделать	Команда
Узнать код машины	python encoder.py machine
Защитить один файл без привязки	python encoder.py protect app.py --no-machine
Защитить один файл с привязкой и сроком	python encoder.py protect app.py --machine auto --expire-days 30
Запустить защищённый файл	python encoder.py run app.guarded.py
Пакетно защитить всю директорию	python main.py ./project --key mykey --machine auto
Пакетно защитить (интерактивно)	python main.py
